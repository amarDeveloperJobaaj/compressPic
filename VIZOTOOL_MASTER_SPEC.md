# Vizotool Master Development Specification

## Overview

Master roadmap for Vizotool. Reuse the existing architecture and never
recreate or redesign the project.

## Core Rules

-   Do not recreate the project.
-   Do not break existing functionality.
-   Do not rename routes.
-   Do not modify existing tools.
-   Reuse existing UI, theme, animations and utilities.
